# Reports and Email Configuration Guide

## Overview

The HomeNews AI Agent now automatically saves all intermediate reports in markdown format and can send them via email. This feature ensures you have a complete record of all generated content and can receive daily briefings directly in your inbox.

## Features

### 1. Automatic Report Saving

All intermediate reports are automatically saved to a dated folder structure:

```
reports/
  └── 2026-01-26/
      ├── task_1_News_Editor_for_Chinese_Media.md
      ├── task_2_International_News_Analyst.md
      ├── task_3_Global_Legal_News_Curator.md
      ├── task_4_Health_Sports_Science_Reporter.md
      ├── task_5_Health_Science_Analyst.md
      ├── task_6_Comparative_Law_Scholar.md
      ├── task_7_Chief_Researcher_Architect.md
      ├── task_8_Lead_Editor_Humanizer.md
      └── master_research_report.md
```

### 2. Report Types Saved

- **Individual Task Outputs**: Each agent's output is saved separately for detailed review
- **Master Research Report**: The comprehensive markdown report before HTML conversion
- **Backup Model Reports**: If backup models are used, their outputs are also saved with appropriate prefixes

### 3. Email Delivery

Reports can be automatically sent to a configured email address with all markdown files attached.

## Configuration

### Required Environment Variables

#### Email Recipient
```bash
export mailadd="your-email@example.com"
```

#### SMTP Server Configuration
```bash
export SMTP_USER="your-smtp-username@gmail.com"
export SMTP_PASSWORD="your-app-specific-password"
export SMTP_SERVER="smtp.gmail.com"  # Optional, defaults to smtp.gmail.com
export SMTP_PORT="587"  # Optional, defaults to 587
```

### Gmail Configuration Example

If using Gmail, you need to create an App Password:

1. Go to your Google Account settings
2. Navigate to Security
3. Enable 2-Step Verification (if not already enabled)
4. Under "2-Step Verification", find "App passwords"
5. Generate a new app password for "Mail"
6. Use this password as `SMTP_PASSWORD`

### Example Configuration

```bash
# .env file
mailadd="john.doe@example.com"
SMTP_USER="newsagent@gmail.com"
SMTP_PASSWORD="xxxx xxxx xxxx xxxx"  # App-specific password
SMTP_SERVER="smtp.gmail.com"
SMTP_PORT="587"
```

## Usage

### Automatic Operation

When you run the news agent, it will automatically:

1. Create a dated reports directory (`reports/YYYY-MM-DD/`)
2. Save each task's output as a markdown file
3. Save the master research report
4. Send an email with all reports attached (if email is configured)

### Manual Operation

If you don't configure email settings, the reports will still be saved locally and you'll see a warning message:

```
⚠️ Email address (mailadd) not configured, skipping email send
```

or

```
⚠️ SMTP credentials not configured (SMTP_USER, SMTP_PASSWORD), skipping email send
```

## Email Content

The email you receive will include:

- **Subject**: `Daily News Briefing - YYYY-MM-DD`
- **Body**: Summary of report generation including section count and file locations
- **Attachments**: All markdown report files

Example email body:

```
Daily News Briefing Report - 2026-01-26

This email contains the daily news briefing reports generated by the AI News Agent.

Report Summary:
- 5 major sections covered
- 8 intermediate reports generated
- All reports attached as markdown files

Reports are also saved locally in: reports/2026-01-26

Please find the attached reports for detailed analysis.

---
Generated by HomeNews AI Agent
```

## Accessing Reports

### Local Access

Reports are saved in the `reports/` directory with date-based subdirectories. You can:

- View them directly in any markdown viewer
- Convert them to PDF or other formats
- Archive them for long-term storage
- Compare reports across different dates

### Download from GitHub Pages

If you're using GitHub Actions for deployment, the reports are also available in the workflow artifacts.

## Troubleshooting

### Email Not Sending

1. **Check environment variables**: Ensure `mailadd`, `SMTP_USER`, and `SMTP_PASSWORD` are set
2. **Verify SMTP settings**: Make sure your SMTP server and port are correct
3. **Check firewall**: Ensure outbound connections on port 587 (or your configured port) are allowed
4. **Review logs**: Look for error messages in the agent output

### Common Issues

**Gmail "Less secure app" error**: Use an App Password instead of your regular password

**Authentication failed**: Double-check your SMTP username and password

**Connection timeout**: Verify your SMTP server and port settings, check firewall rules

### Reports Not Saving

1. **Check permissions**: Ensure the script has write permissions in the working directory
2. **Verify disk space**: Make sure there's enough space for saving files
3. **Review logs**: Look for error messages about file writing

## Security Notes

- **Never commit SMTP credentials** to version control
- Use environment variables or secure secret management
- Consider using app-specific passwords instead of main account passwords
- The `reports/` directory is in `.gitignore` to prevent accidental commits
- Regularly rotate SMTP passwords for security

## Advanced Configuration

### Custom SMTP Server

For other email providers (Outlook, Yahoo, custom servers):

```bash
# Outlook example
export SMTP_SERVER="smtp-mail.outlook.com"
export SMTP_PORT="587"

# Yahoo example
export SMTP_SERVER="smtp.mail.yahoo.com"
export SMTP_PORT="587"

# Custom server example
export SMTP_SERVER="mail.yourcompany.com"
export SMTP_PORT="587"
```

### Multiple Recipients

Currently supports single recipient. For multiple recipients, you can:
- Set up email forwarding rules
- Use a distribution list/group email
- Modify the code to support comma-separated addresses

## Integration with GitHub Actions

The workflow can be configured to use GitHub Secrets for email configuration:

```yaml
env:
  mailadd: ${{ secrets.MAIL_ADDRESS }}
  SMTP_USER: ${{ secrets.SMTP_USER }}
  SMTP_PASSWORD: ${{ secrets.SMTP_PASSWORD }}
```

Add these secrets in your repository settings under Settings → Secrets and variables → Actions.
